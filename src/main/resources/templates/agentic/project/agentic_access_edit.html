Step 1 of 2: the account the agents of run on. After saving you are back on the new-agent form, with this access preselected.

An access is one account the agents of can run on. Each agent picks one on its edit page - there is no default.

OAuth uses the credentials of the host's one interactive `claude login` - every OAuth access, in every project, is that same account. A key or setup token is genuinely this access's own.
